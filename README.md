Таблицы базы данных: users (пользователи), discounts (скидки), products (товары), delivery_points (пункты выдачи), orders (заказы), order_items (товары в заказе)

6. Инструкция по запуску

1. Установить Python 3.8 или новее.
2. Установить библиотеки: pip install openpyxl pillow
3. Запустить создание базы данных: python create_database.py
4. Запустить приложение: python main.py
5. Войти с логином admin и паролем admin123.
6. Нажать кнопку Импорт Excel и загрузить файлы: Tovar.xlsx, user_import.xlsx, Пункты выдачи_import.xlsx, Заказ_import.xlsx.
